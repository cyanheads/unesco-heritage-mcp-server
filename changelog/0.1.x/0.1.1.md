# 0.1.1 — 2026-09-30

## Added

- **`unesco_search_sites`** searches the World Heritage List by keyword, `country`, `category`, `region`, `criteria` (i)–(x), inscription years, `in_danger`, `transboundary`, or `near`, with seven sorts, cursor paging, and facet counts over the whole match.
- **`unesco_get_site`** returns one site's full record by `id_no` or its `whc.unesco.org` page URL: criteria with their meanings, States Parties, coordinates, area, Danger-list year, names in six languages, image credit, and up to `max_components` component parts.
- **`unesco_search_intangible_heritage`** searches the Representative List, the Urgent Safeguarding List, and the Register of Good Safeguarding Practices by keyword, `country`, `list`, inscription years, `multinational`, or `world_heritage_site` (the elements UNESCO links to a site's `id_no`).
- **`unesco_get_intangible_heritage_element`** returns one element's full record by `ich_ref` or its `ich.unesco.org` page URL: description, list, countries, inscription year, concept terms, linked World Heritage sites, and image.
- **`unesco_search_biosphere_reserves`** searches the World Network of Biosphere Reserves by keyword, `country`, `region`, `regional_network`, designation years, `transboundary`, `sids`, or `near`; a transboundary reserve appears once per participating country.
- **`unesco_get_biosphere_reserve`** returns one reserve's full record by `mab_id`: introduction, ecological and socio-economic characteristics, core, buffer, and transition areas with population by zone, and its designation, extension, renaming, and periodic-review years.
- **`unesco_list_reference`** decodes the vocabulary the other tools accept by `topic` (`criteria`, `countries`, `regions`, `intangible_lists`, `biosphere_networks`, `datasets`); `filter` narrows a topic, for example a country name to its ISO alpha-2 and alpha-3 codes.
- **`unesco://site/{id_no}`** resource returns the `unesco_get_site` record as JSON with up to 20 components, plus a `sources` array.
- **`unesco://intangible-heritage/{ich_ref}`** resource returns the `unesco_get_intangible_heritage_element` record as JSON, plus a `sources` array.
- **`unesco://biosphere-reserve/{mab_id}`** resource returns the `unesco_get_biosphere_reserve` record as JSON, plus a `sources` array.
- **`UnescoDataHubService`** loads `whc001`, `ich001`, and `mab001` from the UNESCO Data Hub Explore API v2.1 on first use and answers every call from in-memory snapshots, refreshed after 24 h; a failed refresh keeps the previous snapshot.
- **Configuration**: no API key and no server-specific environment variables; the framework's transport and logging variables apply. Ships as an npm package, a `.mcpb` bundle for Claude Desktop, and a GHCR image that serves Streamable HTTP.
- **Data terms**: every data response carries `sources` (dataset, title, `data_as_of`, license, attribution line) for the CC BY-SA 4.0 datasets, and a load whose dataset metadata reports any other license is rejected.
