# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-02

UNESCO Global Geoparks join as a fourth dataset with search, get, and resource surfaces; unesco_search_sites matches near through a site's components, and the site, reserve, and geopark searches can leave row text out with include_description.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-09-30

First published release — seven read-only tools and three resources over the UNESCO World Heritage List, the Intangible Cultural Heritage lists, and the World Network of Biosphere Reserves, served keyless from UNESCO Data Hub snapshots with CC BY-SA 4.0 attribution on every response.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
